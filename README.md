# TTT layouts

Keyboard rows and key colours for **TTT · Talk to Type**, the Android voice-dictation keyboard
by Mantra Productions, as Marko Bosko uses them.

This holds **only rows and colours**. No prompts, no models, no API keys: applying it leaves your
own prompts (or TTT's built-in ones) and your keys exactly as they are.

## Use it

1. Download `profile-Marko-layout.jetpref`.
2. Put it in `Documents/TTTmini/` on your phone.
3. In TTT: Settings → Profiles → **Marko-layout** → apply.

TTT itself: https://github.com/markoboskoauroville/TTT/releases
